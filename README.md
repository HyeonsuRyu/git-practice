## 🏗️ 프로젝트 구조

```
.
├── index.html               홈 페이지 (모든 사이트 카드 목록)
├── style.css                공통 스타일시트
└── sites/
    ├── neal-fun.html        상세 페이지 템플릿 (복사용)
    ├── knight-only-lives-today.html
    ├── pick-me-up.html
    ├── return-of-mount-hua.html
    ├── star-three-shop.html
    ├── 웹툰추천_류현수.html
    └── 육아일기.html
```

각 상세 페이지는 다음을 포함합니다:
- 🎨 제목과 이모지
- 📝 사이트 설명
- ✨ 추천하는 이유
- 🔗 원본 사이트 링크
- 👤 추천자 이름
